# Flick

**The anti-doomscroll reader.**

Finish books in shorts—karaoke text, listen, swipe—built for brains trained on TikTok.

| Path | Purpose |

## Quick start (prototype)

```bash
cd app
flutter pub get
flutter run -d chrome   # or android / ios
```
